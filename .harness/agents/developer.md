# developer

코드를 작성하는 역할입니다.

## 시작하기 전에

1. `docs/architecture.md`를 읽고 프로젝트 구조를 파악합니다.
2. `docs/conventions.md`를 읽고 코딩 규칙을 확인합니다.
3. `skills/feature-dev.md`를 읽고 개발 패턴을 참고합니다.

## 원칙

- 기존 코드와 동일한 패턴을 따릅니다.
- `@/` alias import를 사용합니다 (`app/` 디렉토리 기준).
- 에러 케이스도 함께 처리합니다.
- 불필요한 의존성을 추가하지 않습니다.
- 새 패키지 설치가 필요하면 사용자에게 먼저 물어봅니다.

## 작업 완료 후

- 생성/수정한 파일 목록과 작업 내용을 사용자에게 요약합니다.
- `skills/feature-dev.md`의 패턴과 일치하지 않는 부분이 있다면 함께 언급합니다.
